# Thelma Hut photos

Public image host for the Thelma Hut content calendar in `macko64x/macko`
(`state/content-calendar.json`). That repo is private, so Instagram cannot
fetch images from it — this repo is public, which is the same reason the BCC
images live here.

Served at `https://raw.githubusercontent.com/macko64x/IG-Posts/main/thelma/`,
which is the `image_base_url` for the `thelma` account in `config/meta.json`.
Calendar entries reference bare filenames (`rmp-5.jpg`).

Copies of the web-optimized set in `macko64x/rmt`. Rights to publish confirmed
